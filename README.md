# Label Studio 项目检查 (Label Studio Monitor)

这是一款轻量级的局域网服务监控与检索工具，专门用于扫描教室内所有学生机器的运行状态，并自动检索其 Label Studio 标注系统中的最新作业项目。

## ✨ 核心特性

- 🌐 **全自动局域网扫描**：基于 Python 并发任务，快速扫描所在网段 (如 `10.74.x.x`)，探测 `8080-8085` 端口。
- 🚀 **底层非阻塞高并发扫描**：弃用重量级的 `asyncio.open_connection`，改用**底层非阻塞原生 Socket (`sock_connect`)** 探测机制。结合 `finally` 强制释放，彻底杜绝 Windows 系统高并发超时下的句柄泄露，并排除任何因连接重置引起的“假阴性”判定 Bug。
- 🛡️ **严格网段格式校验**：内置 `ipaddress` 校验机制，在入口处即阻断一切空参数或非合法 IPv4 网段字符，规避了由于非法输入导致的 **DNS 风暴解析**，确保后台服务在任何异常边界下依然保持极致的敏捷与稳健。
- 🔍 **精确服务识别**：通过特征比对，精确识别端口运行的究竟是否为 Label Studio 系统。
- 🔑 **自动化后台数据抓取**：由 Python 后端静默处理统一账号 (`student@yncjzy.com`) 的跨域表单及 CSRF Token 登录，自动抓取学生机当前的最新项目内容。
- 📊 **现代化的聚合看板**：
  - 自动呈现：IP 地址、状态指示灯、最新的**项目名称**、**项目描述**以及**最后更新时间**。
  - 支持关键字模糊检索特定项目。
  - 直达目标主机的项目页面极速链接。
- 🚀 **极速无刷新的体验**：前后端采用 Server-Sent Events (SSE) 长链接实时回传扫描结果。

## 🛠️ 环境依赖

确保本机已安装 Python 3.7+。然后安装必要依赖包：

```bash
pip install fastapi uvicorn aiohttp yarl
```

## 🚀 极速启动

运行下述命令启动服务：

```bash
python server.py
```

终端将显示启动成功信息，随即打开浏览器访问本地控制面板：
```
http://localhost:3000
```

## 🔒 跨域和登录提示

- 由于前后端隔离和系统网络限制，在浏览器中点击具体某个作业项目链接时，系统会跳转到对应的源地址页面（如 `http://10.74.x.x:8080/...`）。
- 因现代浏览器强化的跨站网络攻击防护 (SameSite 跨域 Cookie 限制与 CSRF 拦截)，**系统无法向你的独立窗口注入账号记录**。
- **最佳做法**：在 Chrome 浏览器中为一台机器登录完成并点击“记住密码”，之后跳转所有学生机均借由 Chrome 自动填充直接回车即可通行无阻。
